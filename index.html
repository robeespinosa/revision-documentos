Se guarda en tu repositorio de GitHub y queda publicado en la web.

Conectar con GitHub

Para subir archivos desde la web hace falta un token. Se guarda solo en este navegador.

  1. Abre github.com/settings/personal-access-tokens/new
  2. En Repository access elige Only select repositories y marca revision-documentos
  3. En Permissions → Contents elige Read and write
  4. Pulsa Generate token y pégalo aquí
